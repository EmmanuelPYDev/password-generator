# Password Generator

A secure password generator gui built with tkinker

## Features

- Generate Secure passwords
- Custom password lenght
- Clipboard Copy support
- Password History viewer
- Generate multiple password
- Password strenght Analysis
- File-based password storage
- GUI Interface

## Requirements

- python 3.8+

## Usage
 
- Run password_generator_gui.py
- Select password options
- Click generate
- Copy or Save password
